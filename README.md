## 💾 career_query.sql

```sql
SELECT *
FROM analyst_profile

WHERE role IN
(
    'Data Analyst',
    'BI Analyst',
    'Analytics Engineer'
)

AND skills IN
(
    'SQL',
    'Power BI',
    'DAX',
    'Python',
    'Data Modeling'
)

ORDER BY continuous_learning DESC;
```
